## 本地真实链路验证

已对网页 → Nginx → Python → Java 的实际链路检查登录、会话恢复、明确报名、原编号重试和取消后重放。短暂停止业务服务时，前端保留待确认请求；刷新并重新登录后仍使用原编号恢复。切换用户无法读取他人会话。

“没过期的活动发出来”经过真实模型的追问理解、意图检查与路由后，返回的活动编号集合与 Java 原始数据按查询时刻筛选的结果一致。筛选在程序中执行，未依赖模型自行比较日期。
